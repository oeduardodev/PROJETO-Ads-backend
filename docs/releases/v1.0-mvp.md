## Decisão

Não existe release pública validada nesta revisão. Não criar tag de release, publicar catálogo ou iniciar deploy. Há um Compose local loopback para testar infraestrutura e browser→API real com catálogo vazio; domínio de staging/produção continua sem escolha, a URL pública da API e do site Angular está vazia e `catalogEnabled` é `false`. Nenhum edital/processo está aprovado para exibição pública. A consulta pública não deve depender de IA. Há consumers `source.refresh` e `url.fetch` para fixtures; fora de teste, o fetch bloqueia até storage/retenção oficial aprovados. Ainda não há jornada única validada de classificação/extração até curadoria, API real e browser.

## Bloqueios para reabrir a release

1. Escolher provedor, domínio, storage privado e política de retenção; provisionar ambiente isolado e secrets (ADRs 0008, 0041 e 0043).
2. Obter revisão de acesso/licença por fonte; confirmar diretamente UEPB; ativar fontes apenas após registro humano de autorização e revisão.
3. Decidir storage/retenção oficial; conectar classificação/extração, replay idempotente, aprovação de processo sintético revisado, consulta do mesmo processo pela API real e browser sem mocks.
4. Fazer QA manual de leitor de tela, staging E2E, backup/restore e rollback, permissions/rulesets e incidentes.
5. Completar e revisar aviso editorial, privacidade e termos com o responsável pelo serviço e informações reais de contato/retention. Não inventar controlador ou canal.
6. Revalidar todos os gates e obter autorização explícita antes de qualquer publicação/produção.

## Verificação local deste checkpoint

Em 2026-11-11 (America/Sao_Paulo), `corepack pnpm test:e2e:offline` passou com backend 5/5, integração PostgreSQL/Redis 25/25 e Playwright 4/4. Uma execução anterior encontrou a fixture sintética deixada pelo ensaio de restore 081 (24/25); os dois registros identificados foram removidos do banco descartável e a execução agregada seguinte passou. Essa suíte não liga os passos em um pipeline único e o browser usa API simulada.

Depois dessa avaliação, o passo 080 acrescentou Compose apenas local: imagens de web/API/worker construíram, as 16 migrations foram aplicadas manualmente no volume `alem_staging`, readiness e rotas públicas retornaram HTTP 200 e Playwright sem mocks passou 1/1 com catálogo honesto vazio. O passo 081 restaurou a base vazia em um banco temporário separado, comparando 16 migrations, contagens e hashes. O passo 082 releu índices oficiais sem baixar editais. Isso não supre consumers BullMQ integrados, fonte ativa autorizada, processo real revisado, homologação externa, backup gerenciado, rollback ou gate G5.
