- Estado: **RETIDA — não publicar**.

## Decisão

Não existe release pública validada nesta revisão. Não criar tag de release, publicar catálogo ou iniciar deploy. A avaliação é local e documental; o domínio de staging/produção não foi escolhido, a URL de API e domínio públicos no Angular estão vazios e `catalogEnabled` é `false`. Nenhum edital/processo está aprovado para exibição pública. A consulta pública não deve depender de IA, mas não há uma jornada única validada entre fontes, consumers, curadoria, API real e browser.

## Bloqueios para reabrir a release

1. Escolher provedor, domínio, storage privado e política de retenção; provisionar ambiente isolado e secrets (ADRs 0008, 0041 e 0043).
2. Obter revisão de acesso/licença por fonte; confirmar diretamente UEPB; ativar fontes apenas após registro humano de autorização e revisão.
3. Conectar consumers, replay idempotente, aprovação de processo sintético revisado, consulta do mesmo processo pela API real e browser sem mocks.
4. Fazer QA manual de leitor de tela, staging E2E, backup/restore e rollback, permissions/rulesets e incidentes.
5. Completar e revisar aviso editorial, privacidade e termos com o responsável pelo serviço e informações reais de contato/retention. Não inventar controlador ou canal.
6. Revalidar todos os gates e obter autorização explícita antes de qualquer publicação/produção.

## Proibição vigente

Este registro não é anúncio de lançamento nem release note para usuários. Não houve push, publicação, deploy ou migration de produção. O conjunto de critérios e evidências, inclusive pendências, está em `docs/implementation/PROGRESS.md` e `docs/quality/gates.md`.
